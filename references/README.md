# Casa Inteligente — Biblioteca de Referencias

Esta carpeta conserva los proyectos que pueden formar parte de la futura casa inteligente de Alejandro.

## Objetivo

- Mantener Lúmina completamente separada.
- Priorizar control local, privacidad y funcionamiento sin Internet.
- Ejecutar servicios principales en Ubuntu Server + Docker.
- Mantener acceso remoto mediante ZeroTier.
- Reutilizar proyectos maduros antes de desarrollar soluciones desde cero.
- No guardar contraseñas, tokens, claves Wi‑Fi, direcciones, IP públicas ni secretos en este repositorio.

## Repositorios propios ya disponibles

- [AlejandroSanto17/smart-home](https://github.com/AlejandroSanto17/smart-home) — fork de `nsteps/smart-home`; base principal de referencia.
- [AlejandroSanto17/smart-home-infrastructure](https://github.com/AlejandroSanto17/smart-home-infrastructure) — fork de `Marvin1912/smart-home-infrastructure`.
- [AlejandroSanto17/SmartHomeStack](https://github.com/AlejandroSanto17/SmartHomeStack) — stack Docker de referencia.
- [AlejandroSanto17/nas-ha-home-lab](https://github.com/AlejandroSanto17/nas-ha-home-lab) — referencia para NAS/Home Assistant.
- [AlejandroSanto17/homelab-infrastructure](https://github.com/AlejandroSanto17/homelab-infrastructure) — infraestructura general de homelab.
